# depgraph — визуализатор графа зависимостей (вариант 17, pip)

## Общее описание

Консольный инструмент для анализа зависимостей Python-пакетов (формат
pip). Конечная цель работы — построить граф зависимостей пакета и
вывести его на языке PlantUML. Готовые менеджеры пакетов и библиотеки
для получения зависимостей не используются.

**Реализованы этапы 1–3**: конфигурация, получение зависимостей,
построение транзитивного графа (BFS), фильтр, циклы, тестовый режим.

## Параметры конфигурации (YAML)

| Параметр       | Обязателен | Описание                                             |
|----------------|------------|------------------------------------------------------|
| `package_name` | да         | имя анализируемого пакета                            |
| `repository`   | да         | URL репозитория (корень JSON API, напр. `https://pypi.org/pypi`) или путь к файлу тестового репозитория |
| `test_mode`    | нет        | `true` — `repository` это файл; по умолчанию `false`  |
| `filter`       | нет        | подстрока: пакеты с ней в имени не анализируются (без учёта регистра) |

## Как это работает

- **Данные.** Для реального репозитория читается
  `<repository>/<имя>/json` (PyPI JSON API через `urllib`), из
  `requires_dist` берутся имена прямых зависимостей. Необязательные
  (`extra`) пропускаются, версии и условия среды игнорируются.
- **Граф.** Строится обходом в ширину (BFS) с очередью, без рекурсии.
  Каждый пакет посещается один раз, поэтому циклы не зацикливают
  программу.
- **Фильтр.** Пакет, имя которого содержит подстроку `filter`, и всё,
  что доступно только через него, в анализ не попадает. Если под фильтр
  попал сам корневой пакет — ошибка.
- **Циклы.** После построения граф проверяется итеративным обходом в
  глубину; найденные циклы выводятся (`A -> B -> A`, самозависимость
  `A -> A`).
- **Недоступная зависимость.** Если зависимость не найдена в
  репозитории, выводится предупреждение, пакет считается листом.
  Отсутствие корневого пакета — ошибка.

### Тестовый репозиторий

При `test_mode: true` параметр `repository` — путь к текстовому файлу:

```
# комментарий
A: B C
B: D
C: D
D:
```

Строка `ИМЯ: ЗАВИСИМОСТИ через пробел`; имена — заглавные латинские
буквы. Ошибки (с номером строки): нет двоеточия, недопустимое имя,
повторное описание пакета. Примеры лежат в `examples\repos`.

## Установка, запуск и тесты

Нужен Python 3.8+ (интернет — только для запуска с реальным PyPI).

```
pip install -r requirements.txt
run.bat --config configs\test_cyclic.yaml
python -m unittest discover -v
scripts\demo_stage3.bat
```

Тесты не требуют интернета.

## Примеры

```
C -> A, D

  A -> B -> C -> A

> run.bat --config configs\test_filter_b.yaml

Ignoring packages with 'B' in the name

C -> D
D -> (no dependencies)
Packages: 3, dependencies: 2

```
